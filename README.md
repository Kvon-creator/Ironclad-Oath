# Ironclad Oath: The Grand Crossing

A turn-based tactical grid combat prototype inspired by classic 16-bit strategy RPGs, featuring directional armor mitigation, zone of control interrupts, formation auras, and environmental Bloom corruption.

---

## Quick Start Guide

### Prerequisites
* **Python 3** (installed by default in GitHub Codespaces and most modern environments)
* A modern web browser (Chrome, Firefox, Edge, Safari)

---

### Running the Web Game (Recommended)

1. Open your terminal in the root project directory:
   ```bash
   cd /workspaces/Ironclad-Oath
2. Start a local HTTP server using Python:
   ```bash
   python3 -m http.server 8000
3. Launch the game in your browser:
   * GitHub Codespaces / VS Code Remote: Click the "Open in Browser" notification in the bottom-right corner,
     or open the Ports tab next to your terminal and click the globe icon for port 8000
   * Local Machine: Open your browser and navigate to:
   ```bash
   http://localhost:8000
